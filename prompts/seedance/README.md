## 편끼리 이어지는 고리

- **패턴 월** (90칸 라인차트) — 1편 마지막 화면 = 2편 첫 화면

- **검은 케이스** — 2편 마지막 빈 펜트하우스 바닥 = 3편 첫 장면
- **왼손목 밴드** — 4편에서 채우고 5편 내내 보임
