# 네온 성수 (Neon Seongsu)

A GTA-style top-down cyberpunk game set in Seongsu-dong, Seoul in 2077. It's a single HTML file with no build step and no dependencies.

**Play:** open `index.html` in a browser.

- 6 story missions from the fixer "Mira": delivery, hacking, Han River race, OMNI truck chase, Seoul Forest drone raid, final heist at OMNI Tower
- Open world: Line 2 elevated tracks with Seongsu/Ttukseom stations, Seoul Forest, Yeonmujang-gil café street, the shoemaker street, red-brick warehouses, the Han River and Jungnangcheon
- Traffic AI with lane-following, pedestrians with neon umbrellas, carjacking, 5-star wanted system with police cars and drones, EMP
- Procedural radio (3 stations) via Web Audio, minimap with GPS routing, 15 hidden data chips
- Keyboard (WASD / F / E / Space / Q / R / M / H / P) and touch joystick controls
- Progress is saved in `localStorage`
