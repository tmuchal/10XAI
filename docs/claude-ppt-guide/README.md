## 5단계 요약

### STEP 1 · 자료 넣기
관련 자료(엑셀, PDF, 회의록, 회사 템플릿)를 **한 번에** 첨부하고 네 가지를 적습니다.

- **청중**: 누구에게 보고하나? (예: 대표이사·임원, 10분)
- **목적**: 무엇을 얻어야 하나? (예: 실적 공유 + 선급금 승인)
- **분량**: 몇 장? (예: 8~10장)
- **결정 요청**: 보고 끝에 무엇을 결정받나?

### STEP 2 · 스토리라인
바로 슬라이드를 만들지 말고 **목차와 메시지부터** 받아 확인합니다.

```
슬라이드별 제목과 핵심 메시지를 목차로 먼저 보여 줘. 내가 확인한 뒤에 만들어 줘.
```

제목은 '주제'가 아니라 '결론'으로 씁니다.

| ✗ 주제형 제목 | ✓ 결론형 제목 |
|---|---|
| 3분기 매출 현황 | 3분기 매출 482억, 전년 대비 18% 성장 |
| 채널별 분석 | 온라인 비중 31%로 확대, 성장 견인 |
| 향후 계획 | 빠른 성과 과제 2건, 10월 즉시 착수 |

### STEP 3 · 차트·도표
| 메시지 | 차트 |
|---|---|
| 비교 | 막대 그래프 |
| 추이 | 꺾은선 그래프 |
| 구성 (비중 변화) | 누적 막대 (원형은 항목 3개 이하일 때만) |
| 증감 원인 | 워터폴 |
| 우선순위 | 2×2 매트릭스 |
| 단계·일정 | 프로세스(화살표) |

강조할 곳까지 말하면 완성도가 올라갑니다.

```
'분기매출' 시트로 전년 대비 막대그래프를 만들어 줘.
3분기만 강조색, 값 라벨 표시, 격자선은 빼 줘.
계산 과정(증감률)도 같이 보여 줘.
```

도표도 문장으로 요청하면 PowerPoint 도형으로 그려 주므로 받은 뒤에도 수정할 수 있습니다.

```
4단계 실행 로드맵을 화살표 프로세스로 그려 줘.
영업이익 증감(전년 대비)을 워터폴로 보여 줘.
과제 5개를 효과×난이도 2×2 매트릭스로 배치해 줘.
```

### STEP 4 · 회사 템플릿 적용
```
첨부한 회사 템플릿의 색상·폰트·로고 위치를 그대로 따라 줘.
강조색은 슬라이드당 한 곳만 써 줘.
```

### STEP 5 · 검수 (사람이 마지막으로)
- [ ] 숫자는 원본과 대조했나? → `모든 숫자의 출처 셀을 표로 정리해 줘`
- [ ] 슬라이드 한 장에 메시지 하나인가?
- [ ] 제목만 이어 읽어도 이야기가 되나?
- [ ] 출처와 단위를 표기했나? (단위 통일, 본문 14pt 이상)
- [ ] 올려도 되는 자료인가? (기밀·개인정보는 회사 AI 사용 규정을 먼저 확인)

검수도 Claude에게 먼저 시켜 보세요.

```
이 PPT를 대표이사 입장에서 검토하고, 약한 논리 · 숫자 불일치 · 오탈자를 표로 정리해 줘.
```

## 그대로 쓰는 프롬프트 템플릿

```
[역할] 너는 전략기획팀의 보고서 전문가야.
[자료] 첨부: 3분기_매출.xlsx, 회의록.docx, 회사템플릿.pptx
[청중·목적] 임원 보고 10분 / 실적 공유 + 선급금 12억 승인
[구성] 8~10장, 결론 먼저, 제목은 결론형 문장
[시각화] 슬라이드마다 차트·도표 1개, 강조색 1곳, 편집 가능한 차트
[진행] ① 목차와 메시지 먼저 → 내 확인 후 ② .pptx 생성
```

## 다시 만들기

필요 도구: Node.js, `pptxgenjs`, `playwright`(Chromium), Python 3 + `numpy`, `ffmpeg`, LibreOffice(슬라이드 이미지 생성용), 한글 폰트(Noto Sans CJK KR).

```bash
cd docs/claude-ppt-guide/src
# 1) 예시 PPT 생성 (네이티브 차트)
node build-deck.cjs ../sample-company-deck.pptx
# 2) 슬라이드 이미지(영상에 삽입) — slides/slide-1.png … slide-9.png, 1920px 폭
soffice --headless --convert-to pdf ../sample-company-deck.pptx   # 이후 PDF를 PNG로 변환
# 3) 배경음악 (직접 합성, 저작권 문제 없음)
python3 make-music.py 161 music.wav
# 4) 영상 렌더링 — video.html을 프레임 단위로 캡처해 ffmpeg로 인코딩
node render-video.cjs video.html ../claude-ppt-guide.mp4 --music music.wav
```

`video.html`의 각 `<section class="scene" data-dur="초">`가 한 장면이며, 자막은 장면 안의 `text/x-cap` 스크립트에 `[시작초, "문장"]` 형식으로 들어 있습니다. 문구나 길이를 바꾸면 위 4단계를 다시 실행하면 됩니다.
