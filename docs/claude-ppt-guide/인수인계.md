## 2. 레퍼런스 영상과 그 구성 분석

사용자가 준 레퍼런스: `theater-final-preview.mp4` (3분 12초, 1280×720, 30fps). 세션 업로드 파일이라 저장소에는 없습니다. 아래는 1초 간격 캡처로 읽은 내용이며, 숫자·출처는 화면에서 읽은 값이라 원본 확인이 필요합니다.

### 형식과 스타일
- 빨간 벨벳 커튼(금색 술), 하늘·구름 파스텔 배경, 나무 무대 바닥으로 된 극장 무대.
- 등장: **우추**(빨간 우주복, 초록 얼굴, 더듬이, 놀라면 입이 "O"), **노아**(선글라스·노란 스카프 햄스터, 쿨한 가이드), 무대 앞 **햄스터 관객**(일부는 고깔모자).
- 자막: 하단 남색 박스(점선 스티치 테두리)에 **영어 한 줄 + 한국어 한 줄**(한국어는 노란색).
- 좌상단에 `CHAPTER 0N` 챕터 카드, 우상단에 작은 **출처 표기**(예: "출처: StoryBrand SB7 · Donald Miller").
- 챕터가 바뀔 때 커튼이 닫히고 가운데에 챕터 간판(한국어 제목 + 영어 부제)이 걸립니다.
- 무대 위 콘텐츠는 실제처럼 보이는 웹페이지·폰 화면 목업, 수치 그래프, 소품(룰렛, 저울, 퍼널, 보드게임 길)로 설명합니다.

### 우리 영상에 가져온 것
극장 무대·커튼 챕터 전환, 우추·노아·햄스터 관객, 남색 스티치 자막 박스, "문제 제기 → 방법 → 증거" 흐름. 아직 가져오지 않은 것: 영어+한국어 2줄 자막, 우상단 출처 표기, 한 장면 한 수치 강조 방식.

## 4. 캐릭터 설정과 캐릭터 시트 규격

> 이름 확인 필요: 사용자는 "우찰"이라고 썼고, 작업 파일과 영상에는 모두 **우추(Uchu)**로 되어 있습니다(레퍼런스 영상의 빨간 글씨 "uchu"에서 따옴). 어느 쪽으로 확정할지 정해 주세요.

### 우추 (Uchu) — 주인공
- 역할: 예전엔 PPT 때문에 밤새던 사람. 단계마다 "예전엔…" 하고 고생담을 꺼내고, 새 방식을 보면 놀람. 30초 브리핑에서는 내레이터.
- 외형: 빨간 원피스 우주복(몸통 둥근 사각형), 후드 양옆 둥근 귀마개, 더듬이 2개(끝에 공), 후드 구멍 안 **초록 얼굴**, 눈 밑 연두색 세로 줄, 큰 흰 눈 + 갈색 눈동자, 평소 작은 "o" 입 → 놀라면 큰 "O"(분홍 혀).
- 색: 빨강 `#E0312B`, 진빨강 `#B8231F`, 초록 `#4FA83A`, 줄무늬 연두 `#A8DB7C`, 외곽선 `#2B2118`.
- 표정: 기본 / 웃음(눈 ^^, 입 D) / 놀람(눈 크게, 입 O) / 물음표. 동작: 대기 호흡, 깡충, 손 흔들기, 가리키기, 걷기.
- 구현: 극장 편은 2D SVG(`src/video.html`의 `UCHU`), 30초 브리핑은 Blender 3D 모델(`v3/scene3d.py`의 `build_uchu`, 립싱크·손짓 포함).

### 노아 (Noa) — 가이드
- 역할: Claude 쪽 설명 담당. 가리키며 요점을 짚고 "같이 만들어요!" 같은 짧은 대사. 레퍼런스처럼 "쿨해서 눈을 안 마주치는" 선글라스 캐릭터.
- 외형: 통통한 주황 햄스터(`#E9A04A`), 크림색 배·주둥이(`#FBE6C4`), 분홍 귀 안쪽, **검은 선글라스**(흰 반사광), 수염, 노란 스카프(`#F2C94C`, 오른쪽으로 끝자락).
- 표정: 선글라스라 눈 대신 **눈썹·입**으로 표현(기본 ω 입 / 웃음 / 놀람 O).
- 구현: 2D SVG(`src/video.html`의 `NOA`). 3D 모델 없음.

### 그 밖의 등장인물
- **햄 부장**: 연갈색 햄스터, 둥근 안경, 흰 눈썹 뭉치, 회색 정장 + 빨간 넥타이. 완성본을 보고 "오, 한눈에 보이네!", 검수 끝에 "좋아, 승인!".
- **햄스터 관객**: 무대 앞 좌우 6마리, 3마리는 고깔모자. 평소엔 까딱이고 색종이 장면에서 점프.

### 캐릭터 시트 규격 (제안 — 아직 파일로 만들지 않음)
레퍼런스 CH 03의 방식을 따른 규격입니다. Higgsfield(Soul ID·레퍼런스 요소)에 넣어 얼굴·의상을 고정하는 용도입니다.
- 캐릭터당 1장, **2048×1152 PNG(16:9), 흰 배경** + 각 뷰를 1024×1024 투명 PNG로 따로 저장.
- 뷰 4개(의상 하나로 고정): ① 정면 FRONT ② 3/4 THREE-QUARTER ③ 측면 SIDE ④ 얼굴 클로즈업.
- 표정 줄 4개: 기본 / 웃음 / 놀람 / 물음표. 손짓 3개: 가리키기 / 손 흔들기 / 깡충.
- 색상 칩(위 HEX)과 이름·키 비율(우추 ≒ 머리:몸 1:1, 노아 ≒ 몸 전체가 공 모양) 표기.
- 고정 요소: 우추 = 더듬이 2개·귀마개·눈 밑 줄, 노아 = 선글라스·노란 스카프. 의상·헤어(털색) 바꾸지 않기.
- Soul ID용 참고 이미지가 필요하면 위 시트에서 각도·조명을 달리한 20장 이상.

## 5. 확정된 것 / 아직 안 정한 것 / 사용자가 지적한 문제

### 확정된 것
- 메인 영상은 **3분 이내**(현재 2:58), **16:9 1920×1080**.
- 스타일은 레퍼런스를 따른 **극장 무대**(빨간 커튼, 챕터 전환 커튼, 햄스터 관객, 남색 스티치 자막).
- 캐스트: 우추(주인공) · 노아(가이드) · 햄 부장 · 햄스터 관객.
- 구성 원칙: **"예전엔 손으로 밤새 → 이제는 Claude와"** 전/후 비교로 단계마다 전개.
- 최신 Claude 기능 반영(2026년 9월, 공식 문서 확인): Claude for PowerPoint 추가 기능(슬라이드 마스터 읽기, 콕 집어 수정, 네이티브 차트·도표, 설정의 지침), Excel·Word와 작업 간 연결, Claude 앱 대화의 .pptx 생성, Claude Design(연구 프리뷰, PPTX·Canva 내보내기).
- 실사 이미지·영상은 **Higgsfield**를 쓰는 것으로 방향 확정.
- 연출: 콜드 오픈(새벽 2시), 가상 카메라, 조명·먼지, 커튼 챕터 전환.
- 30초 브리핑은 영어 음성 + 한/영 자막, 스타트업 덱 스타일, Blender 3D.

### 아직 안 정한 것
- **올릴 곳**(유튜브·사내 교육·SNS 등)과 그에 맞춘 썸네일·세로 버전 여부.
- 메인 영상 **내레이션**: 지금은 음성이 없고 자막 + 음악만 있음. 레퍼런스처럼 음성을 넣을지, 영어/한국어 중 무엇으로 할지.
- 메인 영상 **자막 언어**: 지금은 한국어 1줄. 레퍼런스처럼 영어+한국어 2줄로 할지.
- 주인공 이름 표기: **우추 vs 우찰**.
- Higgsfield **실제 생성물**: 연결이 안 돼 제품 사진·영상은 Blender 대체 이미지("예시" 표기).
- **캐릭터 시트 파일**: 규격만 정했고 파일은 없음.
- 배경음악: 코드로 합성한 임시 트랙. 실제 음원으로 바꿀지.
- 실제 회사 데이터 사용 여부(지금은 전부 예시 데이터 "누리테크").
- 30초 브리핑을 메인 영상과 별도 콘텐츠로 둘지, 합칠지.
- 출처 표기(레퍼런스처럼 화면 우상단에 넣을지).

### 사용자가 지적한 문제 (요청 순서대로, 반영 상태)
1. 첫 영상은 레퍼런스 느낌으로, 캐릭터는 바꿔서 → 수채화 극장 + 새 캐릭터로 제작(이후 다시 레퍼런스 캐릭터로 교체).
2. "손으로 그린 90년대 스타일에서 벗어나, 스타트업 덱처럼 전문적이고 화려하게. 데이터로 과거·현재·미래, 주간·월간, 마일스톤까지. 힙한 햄스터 주인공, 영어 음성 + 영/한 자막, 30초, 점수 매기고 약한 부분 재작업" → 30초 브리핑 v1(평균 7.1) → v2(8.1)로 재작업.
3. 우추 이미지로 캐릭터 → 주인공으로 → 30초 브리핑 주인공을 우추로 교체.
4. "영상 여기서 못 틀어?" → 재생 페이지(아티팩트) 제작.
5. "PPT 만들기 내용은 원래 힘들게 만들던 걸 만드는 것이니 수정·정돈" → 전/후 비교 구성으로 재편.
6. "정적으로 흘러가면 안 됨, 영상미·몰입감 더, 최신 정보 반영" → 카메라·조명·커튼 전환, 최신 Claude 기능 반영.
7. 레퍼런스 영상 참고해 캐릭터 → 우추·노아·햄스터 관객·남색 자막으로 교체.

9. "현실적이고 프로페셔널하게, 실제 이미지·영상은 Higgsfield, 훨씬 고도화" → **부분 반영**: Higgsfield 장면은 추가했지만 실제 생성물은 없음(연결 불가). 화면 대부분이 여전히 만화 무대라 "현실적" 요구는 덜 충족됨.

2. 캐릭터 시트 제작 → Higgsfield Soul ID·레퍼런스로 우추·노아 고정.

4. 내레이션·자막 언어·올릴 곳 확정 후 재렌더.

- 메인 영상: `cd src && npm install` → 배경·음악·슬라이드 PNG·제품 렌더 생성(README "다시 만들기" 참고) → `node render-video.cjs video.html ../claude-ppt-guide.mp4 --music music.wav`. 4코어 기준 30~40분.
