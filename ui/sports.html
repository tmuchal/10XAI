1 · YouTube match

Paste a highlight or full-match URL. Metadata comes from YouTube's official oEmbed endpoint. Downloading the video or captions breaks YouTube's Terms of Service without the rights holder's permission, so those steps are held at the gate for manual approval.

2 · Commentary → events

Paste the video's transcript (YouTube: ⋯ → Show transcript). Each action is credited to the nearest roster player named before it. Commentary covers headline actions (goals, shots, threes), so passing volume stays thin. For full ratings, import a tagged event log (npm run sports -- import events.csv).

3 · Player ratings

Each rating is 1–99: 50 is the average player in your data, and every 15 points is one standard deviation. Small samples are pulled toward average.

4 · Predict the next match

Team Elo is built from past results, then shifted by the lineup's player ratings relative to the team's usual roster. Leave the lineups empty to use the usual roster.

5 · Does it actually predict? (walk-forward backtest)

Each past match is predicted using only earlier data, then compared with the real result. The baseline always predicts the historical outcome rates. Lower Brier is better.
