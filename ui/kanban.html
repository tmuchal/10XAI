📖 10XAI Guide

What social promises vs. what actually works — know before you waste time.

10XAI verifies whether the "build a SaaS with one prompt" AI workflows floating around X / LinkedIn / YouTube actually work, and compiles them into runnable execution modules. It exposes cherry-picking, bait paywalls and hidden costs with real measurements.

How to use (3 steps)

1. Paste an X / LinkedIn post URL or a GitHub repo URL into the input at the top and click [Decompose · Verify].

2. 🔍 Verify pipeline — decompose → gap-fill (restore missing steps) → verify multi-agents judge security / policy / reproducibility → risky steps stop at the gate.

3. ⚙ Execute pipeline — approve "Move on to execution? [Yes]" → sandbox measures N runs (success rate / real cost / time) → output → accumulates in the library.

What if you paste an X tweet?

It fetches the tweet text (syndication API), finds the GitHub repo linked inside it, and pulls its README / skills to decompose.

📁 Folder setup (required for deployment)

The output folder for verify/execute artifacts is set via repoPath in config.js. Anyone cloning this repo from GitHub must change it to their own path. The currently configured folder is shown in the 📁 Output folder indicator at the top.

Local server / claude

The board runs on a local server at localhost:8080 (always on via launchd). Verify and execute are handled by the local claude CLI — no API key needed, it works with your subscription auth. Outputs accumulate in the workspace/ and library/ folders.
